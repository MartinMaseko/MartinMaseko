## Currently building

**[LocalsZA](https://locals-za.co.za)** — a last-mile delivery marketplace and field-sales activation platform for South Africa's informal retail market, two independent products on one codebase:

- A zone-based delivery marketplace with a runtime-editable hybrid pricing engine, atomic race-safe dispatch, and integrated payments.
- A field-sales analytics engine — a medallion (bronze/silver/gold) pipeline built on Python + DuckDB with reverse-ETL into a Cosmos DB serving layer, feeding a per-brand analytics dashboard.

Full architecture write-up: **[localsza-architecture](https://github.com/MartinMaseko/localsza-architecture)**
